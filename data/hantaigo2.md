# 4年国語〈反対語2〉（26）

| No | ことば | 反対語 | ほかの組み合わせ | 例文 |
|---|---|---|---|---|
| 1 | 安心（あんしん） | 不安（ふあん） | 安心⇔心配 | 今日は晴れだと安心していたが、急に黒い雲が出てきて不安になった。 |
| 2 | 安全（あんぜん） | 危険（きけん） |  | 安全ピンという名前であっても、針の先はやはり危険なのだ。 |
| 3 | 円満（えんまん） | 不和（ふわ） |  | 言い争いを円満におさめたつもりだったが、かえって不和を招いてしまった。 |
| 4 | 原因（げんいん） | 結果（けっか） | 理由⇔結果 | 間違いの原因をしっかり考えれば、次こそは良い結果につながるだろう。 |
| 5 | 好感（こうかん） | 反感（はんかん） |  | 彼の行動は周囲の反感を買ってしまうことが多いが、私はむしろ好感をいだく。 |
| 6 | 幸福（こうふく） | 不幸（ふこう） |  | 自分で不幸だと思いこんでいると、ますます幸福から遠ざかってしまう。 |
| 7 | 興奮（こうふん） | 冷静（れいせい） |  | 身近で起こった大事件に興奮したが、一晩たつと冷静になった。 |
| 8 | 賛成（さんせい） | 反対（はんたい） |  | 彼の意見に賛成の人は左へ、反対の人は右へ移動してください。 |
| 9 | 地味（じみ） | 派手（はで） |  | 会社では地味な服装だが、休日には派手な格好をすることもある。 |
| 10 | 勝利（しょうり） | 敗北（はいぼく） |  | 初戦の敗北で味わったくやしさをばねにして、第二戦では勝利を手にした。 |
| 11 | 親切（しんせつ） | 冷淡（れいたん） |  | いつもは親切な彼が、急に冷淡な態度をとったのでおどろいた。 |
| 12 | 成功（せいこう） | 失敗（しっぱい） |  | ミスをくり返したがそのつど改善してやっと作品を完成させ、失敗は成功の母という言葉を実感した。 |
| 13 | 精神（せいしん） | 肉体（にくたい） |  | 世界レベルの選手ともなると、肉体の強さのみならず精神力もけたちがいだ。 |
| 14 | 積極（せっきょく） | 消極（しょうきょく） |  | 転校してきた頃は消極的に見えたが、慣れてくると本来の積極性が出てきた。 |
| 15 | 戦争（せんそう） | 平和（へいわ） |  | つらい戦争の時代が終わり、待ち望んでいた平和が訪れた。 |
| 16 | 単純（たんじゅん） | 複雑（ふくざつ） |  | 今回のテストでは、単純な計算問題はもちろん複雑な応用問題まで出題される。 |
| 17 | 長所（ちょうしょ） | 短所（たんしょ） | 美点⇔欠点 | すぐに行動するのは僕の長所だが、考えが足りないと言われ短所にもなってしまう場合がある。 |
| 18 | 自然（しぜん） | 人工（じんこう） | 天然⇔人工 | エアコンから出てくる人工の風も悪くないが、やはり自然のそよ風が心地よい。 |
| 19 | 満足（まんぞく） | 不満（ふまん） |  | 昨日の弁当は量が少なくて不満だったが、今日のものは満足できるボリュームだった。 |
| 20 | 理想（りそう） | 現実（げんじつ） |  | 理想では二十二時より前に眠っていたいところだが、現実にはなかなか難しい。 |
| 21 | 楽観（らっかん） | 悲観（ひかん） |  | 雨は止むはずがないと悲観的に考えるより、そのうち止むだろうと楽観的に考えよう。 |
| 22 | 有利（ゆうり） | 不利（ふり） |  | 試合が長引き、体力のある選手にとっては有利な、反対に体力のない選手には不利な状況となってきた。 |
| 23 | 決定（けってい） | 未定（みてい） |  | 音楽会の日時や場所は決定しているが、何をやるかは今のところ未定のままだ。 |
| 24 | 困難（こんなん） | 容易（ようい） |  | 容易に手に入れた成功より、困難を乗り越えてたどりついた成功は喜びが大きい。 |
| 25 | 希望（きぼう） | 失望（しつぼう） | 希望⇔絶望 | 失望を一度味わったからといって、すっかり希望を捨ててしまってはならない。 |
| 26 | 肯定（こうてい） | 否定（ひてい） |  | 誰でも頭から否定されると反発したくなるが、少しでも肯定されるとやる気が出るものだ。 |
