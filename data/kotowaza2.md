# 4年国語〈ことわざ2〉（26）

| No | ことわざ | 同じ意味 | 意味 | 例文 |
|---|---|---|---|---|
| 1 | ぬかに釘 | のれんに腕押し／豆腐にかすがい | 何の手ごたえも効き目もないこと。 | 自分のやり方が一番と信じている彼には、どんなアドバイスもぬかに釘だ。 |
| 2 | 馬の耳に念仏 |  | 相手が聞く耳を持たず、意見や忠告を言ってもむだであること。 | ゲームに夢中になっている弟に勉強の重要性を説いても馬の耳に念仏で、ろくな返事が返ってこない。 |
| 3 | 井の中の蛙 |  | 世界の広さを知らず、狭い世界で満足している。 | 全国大会に出場し、レベルの高い選手がたくさんいるのを見て、自分が今まで井の中の蛙だったことを知った。 |
| 4 | 骨折り損のくたびれもうけ |  | 苦労したのになんの利益もなくただ疲れただけである。 | がんばって庭の落ち葉を掃除したのに、翌日の台風でまた落ち葉だらけになってしまった。まったく、骨折り損のくたびれもうけだった。 |
| 5 | 塵も積もれば山となる |  | 小さなものやささいなことでもたくさん集まれば山のように大きくなる。 | 百科事典を一度に読むのはたいへんだが、塵も積もれば山となるのだから、一日に二ページずつ読んでいけば、きっと読み終えることができる。 |
| 6 | 猿も木から落ちる | 河童の川流れ／弘法も筆の誤り | どんな名人や上手な人でも失敗することがある。 | 一度負けたからといってそんなに落ち込むことはないよ。猿も木から落ちるというじゃないか。君の実力はみんなが認めているのだから。 |
| 7 | 鳶が鷹を生む |  | 平凡な親から優秀な子が生まれる。 | 私たち両親はスポーツが苦手なのに、息子はプロ野球の選手になった。鳶が鷹を生むとはこのことだ。 |
| 8 | 蛙の子は蛙 | うりのつるになすびはならぬ | 平凡な親の子は、親に似てやはり平凡である。 | たしかに蛙の子は蛙と言うけれど、自分の子に才能がないなどと早くから決めつけるのはよくない。 |
| 9 | 良薬は口に苦し |  | 他人の忠告を聞くのはつらいものだが、それが自分のためになる。 | 先生から注意されていやな思いをしたが、良薬は口に苦しで、今になってみるとその注意のおかげで自分のよくないところに気づくことができた。 |
| 10 | 泣きっ面に蜂 |  | 悪いことが重なる。 | 今日はまさに泣きっ面に蜂で、転んでひざをすりむいただけでなく、ポケットに入れていた携帯電話の画面まで割れてしまった。 |
| 11 | 猫に小判 | 豚に真珠 | 価値のわからない者に、どんなに価値のあるものを与えても無意味だ。 | 高級なチョコレートをもらったようだが、私にはどのチョコレートも同じ味に思えるので、猫に小判である。 |
| 12 | 立つ鳥跡をにごさず |  | 立ち去る際はその後が見苦しくならないように後始末をしておくものだ。 | キャンプ場から帰る前にもう一度ゴミ拾いをしよう。立つ鳥跡をにごさずだからね。 |
| 13 | 後は野となれ山となれ |  | 目先のことさえよければ、後のことはどうなってもかまわない。 | 友だちから遊びにさそわれた。宿題はまだたくさん残っているけれど、後は野となれ山となれだ。行ってしまおう。 |
| 14 | のど元過ぎれば熱さを忘れる |  | 苦しいことも過ぎ去ってしまえばその苦しさを忘れてしまう。 | 去年は夏休みの宿題が最終日まで終わらずあんなに苦しんだのに、のど元過ぎれば熱さを忘れてしまい、今年もまた同じ状態で夏休み最終日を迎えた。 |
| 15 | 鬼に金棒 |  | もともと強いものが、それ以上に強くなる。 | 去年の優勝チームに今年もすごい選手が二人も入団したのだから、鬼に金棒だ。 |
| 16 | 石橋を叩いて渡る |  | 慎重なうえにも慎重にものごとをおこなう。 | 彼は石橋を叩いて渡るような性格で、ほしいものがあってもすぐには買わず、買った人の話を聞いたり店での評判を調べたりしてからやっと買う。 |
| 17 | 急がば回れ |  | 急いでいる時こそ、多少遠回りに思えても確実な道を進むべきだ。 | 遅刻しそうだから近道を使ってみたいけれど、知らない道で迷ってしまうかもしれない。急がば回れ、いつもの道で行こう。 |
| 18 | 好きこそ物の上手なれ |  | 好きなことは熱心にやるので上達するのが早い。 | 君は将棋を半年前から始めたばかりなのに、毎日練習しているからか、好きこそ物の上手なれということばのとおり、めきめき上達したね。 |
| 19 | 下手の横好き |  | 下手なのにそのものごとが好きで熱心におこなっている。 | 下手の横好きで恥ずかしい話ではあるが、僕は歌のリズムをとるのがちょっと苦手だけれど歌うのが大好きなんだ。 |
| 20 | 身から出たさび |  | 自分の行いが原因で、つらいことや苦しいことを招く。 | 久しぶりに走ると体が重くてたまらない。ふだんの運動不足のせいなので、身から出たさびだ。これからはしっかり体を動かすようにしよう。 |
| 21 | 石の上にも三年 |  | つらいことであっても辛抱して長く続けていれば、きっと成し遂げられる。 | 練習が厳しくてやめてしまいたい気持ちはわかるが、石の上にも三年で、続けていればきっと上達すると信じてがんばれ。 |
| 22 | 能ある鷹は爪を隠す |  | 能力や才能のある者ほど、そのことを自慢したりひけらかしたりしない。 | ふだんは目立たない彼が、リレーでは圧倒的な速さでみんなを驚かせたのを見て、能ある鷹は爪を隠すということばを思い出した。 |
| 23 | 百聞は一見に如かず |  | 百回聞くよりも、自分の目で実際に一回見た方が確かでよくわかる。 | 授業で習ってはいたが、飛行機の窓から三陸海岸のギザギザの海岸線を初めて見たとき、これがリアス海岸なのだと実感した。百聞は一見に如かずだ。 |
| 24 | 雨降って地固まる |  | もめごとや仲たがいの後は、かえって良い結果になるものだ。 | 去年、親友と大げんかをしたが、雨降って地固まるということだったのか、仲直りした後はこれまで以上に絆が深まったと思う。 |
| 25 | 案ずるより産むが易し |  | 始める前はあれこれ心配になるものだが、やってみると案外たやすくできる。 | 塾に入る前は不安だったが、母が「案ずるより産むが易しよ」と励ましてくれた。そのとおり、すぐに友達もできて今では楽しく通っている。 |
| 26 | 灯台下暗し |  | 身近にあるものほど気づきにくい。 | めがねが全く見つからずあきらめかけたとき、灯台下暗しということもあると思ってふと机の上を見たら、なんと、目の前にあるではないか！ |
