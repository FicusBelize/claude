# わが家の献立帳

子どもたちに人気だったレシピをためていき、平日（月〜金）の朝ごはん・夜ごはんの献立を自動で作るツール。
買い物は「土日に1回」と「水曜に1回」の2回に分けて、それぞれの材料リストを出す。

## できること

- **レシピ帳**：料理名、朝/夜/どちらも、子どもの人気（★1〜3）、材料（1行に1つ「名前 分量」）、調味料・家にあるもの（買い物リストに出さない）、作り方（1行に1手順）、メモ
  - 献立のマスやレシピカードの「作り方」から、材料と手順をまとめて見られる
  - 材料は「野菜・果物／肉／魚／卵・乳製品・豆腐／主食・パン・麺／常備（調味料）」に自動で分類
- **今週の献立**：「献立を自動で作る」で月〜金の朝夜10マスを埋める
  - ★が多いレシピほど選ばれやすい
  - 同じ週に同じ夜ごはんは出にくい（朝ごはんは多少くり返してOK）
  - 前の週に出たものは少し出にくい
  - 前後の日の夜ごはんで、鶏・豚・牛・魚が続きにくい
  - 同じ買い物の回の中で材料がかぶるレシピを少し優先（使い切りやすく）
  - 「固定」したマスは作り直しても変わらない／メニュー名から手動で選べる／「かえる」で1マスだけ作り直し
- **買い物リスト**：
  - 土日の買い物 = 月曜朝〜水曜夜の分、水曜の買い物 = 木曜朝〜金曜夜の分（「水曜の夜から」にも切りかえ可）
  - 同じ材料は合計、どの日に使うかも表示、調味料は「家にあるか確認」に分ける
  - チェック欄つき、「LINE用にコピー」でテキストにしてコピー

## 使い方

- Claude のアーティファクトとして公開した版は、データがクラウドに保存される（同じリンクを共有すれば家族で同じ献立を見られる）
- `index.html` をブラウザで直接開いた場合は、そのブラウザの中（localStorage）に保存される
